What happens behind it
LANGUAGEprobabilistic · the only place a model runs
1
POST /api/extract
Vercel Function. The request shape is validated before anything else happens.
2
Nemotron 3.5 Lightning, NVIDIA-hosted
Reads one clause and writes typed requirements. It does the language. It does not reach the decision.
3
Schema gate
The reply has to parse against the domain schema. A rejected reply is sent back once, carrying the reason it was rejected.
4
Labelled fixture fallback
Any model, network or auth failure resolves to a cached fixture that says it is a fixture. A fixture is never relabelled as live.
What the model is never asked: whether the bank can do it. It is asked only what the clause requires. The question it cannot answer is the one we moved across the line.
Response headers report source, attempts, HTTP calls, upstream ms and the first rejection.
➔
DECISIONdeterministic · no model runs here
1
Compile requirements
Atomic and typed, one operation each: receive_notice, fund_draw, book_facility, calculate_interest, collect_fee.
2
Assemble the legs
Every operation names the legs it needs. fund_draw needs all three: notice intake, funding window and booking entity.
3
Exhaustive path search
Every combination of legs is tried, not the first that looks right. A EUR funding window paired with a Toronto booking entity is not a path, it is two capabilities that cannot be used together.
4
Verdict
Worst check decides a path. Best path decides the clause. Unknown never becomes PASS, because a path nothing could evaluate is not a proven path.
Same input, same output, every run. The whole search is covered by unit tests.
The only thing that crosses this line is one typed, schema-validated ExtractedClause. Nothing to the right of it calls a model.

Repair proposal

Challenge mode  /api/challenge
The same bundle goes to a general model. The engine grades its answer against the exhaustive search, the graph's real bounds and the clause's stated facts.

The claim is not that the model is wrong. It is that a direct answer is narrated rather than searched, and that difference is checkable. Grading never calls a model.
